# 🤖 Telegram AI-Userbot Agent

Автономный **ИИ-агент**, отвечающий от лица личного Telegram-аккаунта (Userbot) с использованием моделей **Google Gemini API** и удобной панелью управления в Telegram (**Control Bot**).

---

## ✨ Возможности

- 🟢/🔴 **Главный тумблер**: Мгновенное включение и выключение ИИ-автоответов одной кнопкой в Control Bot.
- 📋 **Белый список (Whitelist)**: ИИ отвечает **только** в разрешенных чатах, исключая случайные ответы.
- 🎭 **Персонализация (Persona)**: Выбор и редактирование системных промптов (стиль общения, характер, правила ответа).
- 🧠 **Контекстная память**: Хранение последних $N$ сообщений и суммаризация старых диалогов для понимания нити беседы.
- 👤 **Имитация человека**: Эмуляция набора текста (`typing...`) и человеческой задержки перед отправкой ответа.
- 🐳 **Docker-ready**: Готовые конфигурации `Dockerfile` и `docker-compose.yml` (PostgreSQL 16 + Redis 7) для деплоя на Proxmox / VPS.

## 🛠️ Быстрый запуск через Docker Compose (Рекомендуется)

### 1. Клонирование и настройка окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

Заполните переменные в `.env`:
- `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` — с сайта [my.telegram.org](https://my.telegram.org)
- `CONTROL_BOT_TOKEN` — токен вашего управляющего бота от [@BotFather](https://t.me/BotFather)
- `ADMIN_TELEGRAM_ID` — ваш личный Telegram ID (узнать в [@userinfobot](https://t.me/userinfobot))
- `GEMINI_API_KEY` — API-ключ от [Google AI Studio](https://aistudio.google.com/)

### 2. Запуск контейнеров
```bash
docker compose up -d --build
```

### 3. Авторизация Userbot (Первичный вход)
При первом запуске Pyrogram попросит ввести номер телефона и код подтверждения от Telegram. Для интерактивного входа выполните:
```bash
docker attach messenger_ai_app
```
*(После ввода кода нажмите `Ctrl+P, Ctrl+Q` для отключения от интерактивной сессии без остановки контейнера).*

---

## 💻 Локальный запуск (без Docker)

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что у вас запущены PostgreSQL и Redis, указанные в `.env`.

3. Запустите приложение:
```bash
python main.py
```

---

## 🎮 Управление агентом

Откройте ваш **Control Bot** в Telegram и нажмите `/start` или `/menu`:

1. **[🟢 ВКЛ] / [🔴 ВЫКЛ]** — переключение глобального состояния ИИ-агента.
2. **📋 Белый список** — добавление чатов по ID или путем пересылки сообщений.
3. **🎭 Настройки Личности** — переключение между пресетами (*Дружелюбный*, *Деловой*, *Ироничный*) или задание своего уникального промпта.
4. **ℹ️ Статус системы** — мониторинг состояния, активной личности и количества чатов в Whitelist.
